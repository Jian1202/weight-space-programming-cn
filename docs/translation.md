# 汉化约定

## 忠实于原意

保留原文结构、论证顺序、实验设置、作者判断和不确定性。特别保留：仅凭权重未能识别迎合模型的结果，以及未能提高 Gemma 数学能力的补充实验。展望部分仍是作者对未来的设想。

## 术语

| 原词 | 采用译法 |
| --- | --- |
| Weight-Space Programming | 权重空间编程 |
| weights | 权重 |
| forward pass | 前向传播 |
| induction / copying head | 归纳头 / 复制头 |
| sycophancy | 迎合用户 |
| harness | 运行框架 |
| paddle | 挡板 |
| token | 词元 |

人名、模型名、数据集和基准名保留可检索的原名。公式的 LaTeX、原始实验代码、权重数值与 JSON 中的结构化测量数据不作翻译。

## 数据与显示

`assets/traces/` 的 JSON 同时包含自然语言和原始实验信息。只修改语言字段，避免改动键名、控制字段、动作回放、权重和分数。公式渲染使用 `vendor/mathjax/es5/tex-mml-svg.js`；动态卡片展开后仍需要调用 MathJax 排版。

## 已知边界

长篇提示词和回答经过机器辅助翻译，可能仍有生硬表达或语境误译。源码中的原始实验代码保留英文注释，方便与日志核对。外部作者主页、论文、模型和在线演示不在汉化范围内。
